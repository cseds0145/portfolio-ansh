# 🌌 Ansh Prajapati — 3D Anti-Gravity Portfolio Website

A futuristic, high-performance, 3D interactive portfolio website built for **Ansh Prajapati** (Computer Science & Engineering Student @ ABES Engineering College, aspiring AI & Software Developer).

---

## 🎨 Visual Identity & Design System
- **Theme:** Minimalist Monochrome + Ice Blue (`#050505` Charcoal Pitch, `#121214` Glassmorphic Surfaces, `#38BDF8` Ice Blue Accent Glow)
- **Aesthetic:** Apple & Vercel design language with spatial zero-gravity interactive 3D physics.
- **Typography:** Google Space Grotesk (Headings), Inter (Body UI), JetBrains Mono (Telemetry & Metrics).

---

## 🚀 Key Features

1. **Interactive 3D Three.js Anti-Gravity Engine:**
   - 1,200+ zero-G ice particles reacting dynamically to mouse coordinates with repulsion & attraction physics.
   - Low-poly floating geometric wireframes (Icosahedrons, Octahedrons, Toruses) with organic drift.
   - 3D Interactive Zero-Gravity Quantum Core with counter-rotating crystal prism and orbital nodes.

2. **Zero-G Floating UI & 3D Parallax Tilt:**
   - Dynamic 3D perspective cards with real-time cursor reflection glare.
   - Zero-gravity badges with sine-wave vertical levitation.
   - Custom magnetic ice-blue follower cursor.

3. **Curated Sections:**
   - **Hero:** Punchy headline, role title, floating skill badges (`Java`, `DSA`, `GenAI`, `Tailwind CSS`), quick CTAs.
   - **About & Education:** ABES Engineering College (B.Tech CSE 2025–2029) and ABES Applied AI Innovation Cell (AAIIC) membership.
   - **Skills Universe:** Categorized glass grid (Languages, Frameworks, Core CS, Tools, Emerging Tech).
   - **Featured Projects:** Amazon Clone Website (Live Demo & GitHub Repo) + 2 future AI/Systems roadmap cards with interactive modal inspect.
   - **Achievements:** CodeChef Bronze Badge (50+ problems solved) and Scaler OOP in Java Certificate.
   - **Contact & Footer:** Direct channels with 1-click copy-to-clipboard, interactive transmission form, developer socials, and return-to-orbit button.
   - **Zero-G Audio Engine:** Ambient space soundscape synthesizer powered by Web Audio API.
   - **Resume Inspector:** Full-screen printable CV modal.

---

## 🛠️ Tech Stack
- **Framework:** React 18 + Vite + TypeScript
- **Styling:** Tailwind CSS + Custom Glassmorphism & Ice Glow Tokens
- **3D Graphics:** Three.js (WebGL)
- **Animations:** Framer Motion + CSS Keyframes
- **Icons:** Lucide React

## 💻 Quick Start

### 1. Navigate to the project directory:
```bash
cd C:\Users\ansh6\.gemini\antigravity\scratch\ansh-portfolio
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Start local development server:
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 4. Build for production:
```bash
npm run build
```
The optimized production bundle will be generated in `dist/`.
